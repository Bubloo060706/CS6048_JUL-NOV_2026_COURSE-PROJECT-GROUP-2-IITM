1. Session setup

Not connected to signaling server.

Open this page in two browser tabs or on two devices using the same room ID. Allow camera and microphone access. Start the call from one participant only; the other participant answers automatically. For remote devices, serve over HTTPS; localhost is permitted for local testing. Each endpoint can export normalized CSV, raw getStats JSONL, browser API snapshots, event logs, or one complete run JSON bundle.
